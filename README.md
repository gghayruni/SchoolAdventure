# Приключения Сероба — v0.1 (играбельный прототип)

Первая автономная браузерная версия сюжетной игры. Сделана без сторонних библиотек: достаточно открыть `index.html` в браузере. Визуальный стиль — яркая рисованная мультяшная 2D/2.5D-графика, **не готовая 3D-игра**. Реальные фотографии служили ориентирами, но 3D-модели по фото пока не созданы.

## Что уже работает
- Последовательные сюжетные задания с подсказками и маркерами.
- Дом на Вавилова, 3, условный 3-й подъезд, вывеска «Ярче!», школа «Эксперт».
- Коридор и лестница на третий этаж; класс с зелёными партами и доской.
- Персонажи: Сероб, Хатун, Гурген, Ольга Сергеевна, Елена Николаевна, условные одноклассники.
- Поездка на серебристом Solaris в рамках сценария (упрощённое аркадное управление).
- Солнце, дождь и снег (можно менять кнопкой «Погода» или клавишей T).
- Диалоги, последовательность миссий, мобильные экранные кнопки.

## Управление
- `WASD` или стрелки — перемещение.
- `E` или кнопка «Действие» — говорить/продолжать задание.
- `T` — сменить погоду; `H` — подсказка; `Shift` — ускорение при ходьбе.
- В режиме автомобиля `A/D` двигают машину по маршруту, `W/S` позволяют менять положение по полосе (упрощённый режим).
- На телефоне есть кнопки движения и действия.

## GitHub Pages (русский интерфейс GitHub)
1. Создайте **новый общедоступный репозиторий** или используйте существующий.
2. В корень загрузите **`index.html`** и `README.md` (через **Добавить файл → Загрузить файлы → Зафиксировать изменения**). Не загружайте один ZIP вместо HTML.
3. Откройте **Настройки → Страницы (Pages)**, выберите **Развёртывание из ветки**, ветку **main**, папку **/(root)** и **Сохранить**.
4. GitHub покажет адрес опубликованной игры в разделе Pages.

## Ограничения v0.1
Это рабочий игровой набросок, а не полноценная трёхмерная сборка: план улиц, фотографии, лица и формы зданий не перенесены точно; «Солярис» и прочие элементы нарисованы условно, звукового оформления нет. В следующих версиях можно заменить визуал на настоящие 3D-модели, проработать сценарий, погоду, физику и навигацию.
