# Дорога в школу — первая 3D-прогулка (Windows)

Это **настоящий исходный проект игры Godot 4.7.2**, а не картинка или макет.
Прототип запускается в отдельном окне. Строения и персонаж создаются программно,
поэтому никакие модели, фотографии или платные ассеты не нужны.

Что реализовано:
- мультяшный 3D-персонаж с рюкзаком;
- ходьба, бег, прыжок и анимация рук и ног;
- камера от третьего лица с поворотом мышью;
- небольшая случайная 3D-застройка: дома, окна, подъезды, витрины, деревья;
- дороги, тротуары, пешеходные переходы, автомобили, остановка, лавочки;
- кнопка N создаёт новый квартал;
- стартовое меню-подсказка на русском языке.

Управление:
- W A S D или стрелки — ходьба
- Shift — бег
- Пробел — прыжок
- Мышь — поворот камеры
- Esc — освободить курсор
- Левая/правая кнопка мыши — снова захватить курсор
- N — создать другой случайный квартал

## Как собрать готовую игру через GitHub

1. Создай **НОВЫЙ PRIVATE репозиторий** `SchoolAdventure`. Не загружай проект в репозиторий G-Vocal.
2. Распакуй архив. Перенеси **содержимое папки** SchoolAdventure-Windows-Prototype в корень репозитория, сохраняя вложенные папки, включая `.github/workflows/build-windows.yml`.
3. Нажми Commit changes. Во вкладке Actions появится `Build School Adventure for Windows`.
4. После зелёной галочки на странице сборки в разделе Artifacts скачай `SchoolAdventure-Windows-Prototype`.
5. Распакуй артефакт и запусти `SchoolAdventure.exe` в Windows.

Если GitHub показывает красный крестик, пришли **первую красную строку** в журнале
`Import and validate project` или `Export Windows EXE`: по ней исправим проблему.

## Как запустить без GitHub

Установи Godot 4.7.2 (обычную версию), открой папку проекта как новый проект,
нажми F6/F5 или кнопку Play. Выполнять экспорт не нужно для тестирования.

## Ограничения первой версии

Первая версия — небольшой **игровой прототип**. В ней нет настоящего ребёнка по фотографии,
школы, заданий, музыки, движения машин, магазина из реального района и сохранений.
Рисунок зданий процедурный; точную художественную доработку и оптимизацию будем делать
после проверки поведения персонажа и камеры.

## Приватность

Этот проект не содержит фотографий детей, адресов, карты маршрута или иных
персональных материалов. Репозиторий должен быть приватным.
